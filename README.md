## **About Project**
### The purpose of this project is to build a data warehouse with SQL Server which includes ELT processes and data modeling. In addition, Exploratory Data Analysis (EDA) and interactive reports are developed by using Power BI. The assumption is that the dataset does not get updated frequently.

## **Dataset Source**
### Pizza Place Sales dataset is downloaded from [MavenAnalytics](https://mavenanalytics.io/data-playground/pizza-place-sales). This dataset is for one year (2015).
